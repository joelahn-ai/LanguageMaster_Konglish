- 처음 보는 단어만 학습, 실제 진도 네모 표시, 상단 이전/다음 버튼
- 미국식 기기 음성, 한영 예문, 내 문장 자동 저장
- 같은 단어의 여러 품사·뜻 전환 (해당 콘텐츠가 있을 때)
- 기간별 내 카드와 이미 본 단어, 양방향 사지선다 시험
- PNG 저장 및 인쇄용 XLSX 내보내기
