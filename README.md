# 언어의 마술사

안드로이드에서 설치할 수 있는 영어 학습 PWA입니다.

- 샘플 단어 36개 / 영어·한국어 예문 108개
- 미국식 기기 음성으로 듣기
- 내 문장 자동 저장, 즐겨찾기, PNG 카드 공유 및 다운로드
- 최초 저장 완료 후 단어·작문·이미지 만들기 오프라인 사용
- 설정에서 개인 기록 JSON 백업·복원

이 브랜치는 공개 배포용 앱 파일만 담습니다. 개인 인계 문서, 실제 학습 기록, 백업 파일, 인증 정보는 포함하지 않습니다.

개인 문장은 각 기기의 브라우저에 저장되며 서버로 전송되지 않습니다. 브라우저 저장소를 지우기 전에 백업하세요. 기기 음성은 인터넷이 필요할 수 있고, 별도 오프라인 음성 파일은 아직 없습니다. 샘플의 최종 언어 검수와 실제 안드로이드 시험은 별도 진행합니다.

앱 파일은 외부 라이브러리 없이 HTML/CSS/JavaScript로 실행됩니다. GitHub Pages 게시 소스는 이 브랜치의 루트입니다. 아이콘은 icons 폴더에 있습니다. 개발용 비공개 자료는 로컬 프로젝트에서 별도로 관리합니다.
# 사용성 업데이트

- 설정 맨 위의 ‘백업 내보내기 / 백업 가져오기’로 기기 사이에 JSON 기록 파일을 옮깁니다. 자동 동기화는 제공하지 않습니다.
- 단어집과 설정에서 ‘현재 단계만 학습 / 이전 단계까지 복습’을 선택할 수 있습니다.
- 같은 단어의 고정 ID를 유지하여 콘텐츠 순서나 난이도가 바뀌어도 개인 문장이 연결됩니다.
