# 언어의 마술사

안드로이드에 설치할 수 있는 영어 학습 PWA입니다.

- 처음 보는 단어만 학습, 실제 진도 네모 표시, 상단 이전/다음 버튼
- 미국식 기기 음성, 한영 예문, 내 문장 자동 저장
- 같은 단어의 여러 품사·뜻 전환 (해당 콘텐츠가 있을 때)
- 기간별 내 카드와 이미 본 단어, 양방향 사지선다 시험
- PNG 저장 및 인쇄용 XLSX 내보내기
- 개인 기록 JSON 백업/가져오기
- 설정에서 공개된 단어집 버전 선택, 오프라인 학습

현재 최신 콘텐츠: vocab-2026-09-10-reviewed36-v1 · 기본 19 / 중급 11 / 확장 6개. AI 편집 검토 완료, 원어민 독립 검수 전입니다. 초기 공개 샘플 버전도 선택할 수 있습니다. 같은 ID의 기록은 버전 사이에 이어집니다. 최종 10,000단어는 향후 제작 목표입니다.

개인 문장은 각 기기에 저장되며 서버로 업로드하지 않습니다. 기기 간 자동 동기화는 제공하지 않습니다. 기기의 음성과 실제 Excel 인쇄 동작은 기기에 따라 확인이 필요합니다.

이 브랜치는 공개 앱 파일만 담습니다. 개인 인계 문서·학습 기록·백업·인증 정보는 포함하지 않습니다. 외부 런타임 라이브러리 없이 실행됩니다.
